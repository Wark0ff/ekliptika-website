# QA сайта «Эклиптика», 14.09.2026

Прод-сборка ветки `site` (коммит 3630e1f), headless Edge по DevTools Protocol.
Ширины: 1440, 1024, 768, 390, 360. Страниц: 14. Кадров: ~400. Сценарии: мобильное меню, фильтр объектов,
якоря, форма (пустая, неверная почта, отправка), FAQ, клавиатура, печать карточки, 404, мобильная смета.
Дополнительно: SEO/доступность по DOM, вес страниц, время появления контента при CPU×4 и 3G.

Не найдено: горизонтальной прокрутки, ошибок консоли, 5xx, битых картинок, пустых ссылок, полей без подписи,
дублей id. Вес страниц 240-550 КБ. Шапка при прокрутке, меню, форма, фильтр и печать работают.

Серьёзность: 3 = мешает задаче, 2 = заметно раздражает, 1 = косметика.
