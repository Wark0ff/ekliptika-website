# Сайт ООО «Эклиптика»

Строительная компания: строительство, реконструкция и отделка зданий в Москве и Московской области.
Дизайн: вариант 1 из макета (тёмный, строгая типографика), утверждён заказчиком. Макет трёх вариантов
заморожен тегом `mockup-v2`. Сайт в ветках `main` (показ на Vercel) и `site` (рабочая).

## Демо на Vercel

Vercel собирает `main` без настроек: фреймворк Next.js определяется сам, переменные окружения не нужны.
Сайт закрыт от индексации (нет `NEXT_PUBLIC_INDEX`). Ограничения стенда:

- контент (объекты, статьи) берётся из `lib/data`, сохранение в админке недоступно: файловая система
  Vercel только для чтения, хранилище и загрузка фото работают на VPS;
- форма заявки без `SMTP_*` и `LEAD_TO` отвечает ошибкой и предлагает позвонить. Чтобы заявки приходили,
  задайте эти переменные в Settings → Environment Variables и пересоберите;
- онлайн-смета скрыта (`/smeta` отдаёт 404), калькулятор сохранён в `components/SmetaCalculator.tsx`.

Основа: кодовая база сайта ТЕРА ГРУПП (админка, форма заявок на почту, блог, объекты, SEO, деплой на VPS),
публичные страницы переписаны в оформлении «Эклиптики». Бриф и решения: [`BRIEF.md`](BRIEF.md).

## Запуск

```bash
npm install
npm run dev
```

Сборка `npm run build`, тесты `npm test`. Не запускайте сборку при работающем `npm run dev`: они делят `.next`.

## Устройство

```
app/
  layout.tsx          корень: шрифт Jost, метаданные, закрытие от индексации до запуска
  site.css            дизайн-система публичного сайта (классы v1-*)
  globals.css         Tailwind для админки и калькулятора
  (site)/             публичные страницы: главная, направления /uslugi/*, объекты, статьи,
                      о компании, контакты, документы, карточка предприятия, политика
  admin/              админка: объекты и статьи, вход по паролю
  api/lead            приём заявок, письмо на почту через SMTP
components/site/      шапка, подвал, форма заявки, карточки, лента направлений, прокрутка и появление
lib/
  brand.ts            реквизиты, контакты, меню (лёгкий модуль, можно в клиентские компоненты)
  site.ts             тексты главной, услуги, условия, этапы, вопросы
  data/               посадочные направлений, стартовые статьи, примеры объектов
  content.ts          JSON-хранилище объектов и статей (CONTENT_DIR), сид из lib/data
public/img/           стоковые фото Unsplash (id исходников в docs/unsplash-ids.txt)
deploy/               nginx, systemd, пошаговая инструкция деплоя на VPS
```

## Переменные окружения

| Переменная | Зачем |
|---|---|
| `NEXT_PUBLIC_SITE_URL` | боевой адрес сайта `https://ekliptika.art`; для сервера задаётся в `deploy/build.env` |
| `NEXT_PUBLIC_INDEX` | `1` открывает сайт поисковикам (до запуска не ставить) |
| `NEXT_PUBLIC_METRIKA_ID` | номер счётчика Яндекс Метрики |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `LEAD_TO` | отправка заявок на почту |
| `CONTENT_DIR` | папка хранилища объектов и статей вне каталога деплоя |
| `ADMIN_PASSWORD_HASH`, `ADMIN_SESSION_SECRET` | вход в админку (`node scripts/gen-admin-hash.mjs "пароль"`) |

## Что предварительное

Помечено `PENDING` в коде: телефон и почта (`lib/brand.ts`), цифры команды и условие оплаты (`lib/site.ts`),
допуски СРО (`app/(site)/documents`). Объекты сейчас только примеры со стоковыми фото: на сайте они помечены
«Пример» и закрыты от индексации. Свои объекты добавляются через админку и выводятся без пометки.
