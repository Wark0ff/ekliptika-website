# Сайт ООО «Эклиптика»: варианты главной

Три варианта главной страницы в фирменной гамме компании (тёмно-синий, золото, знак с орбитой).
Для заказчика они без названий, только «Вариант 1, 2, 3». Отличаются темой, шрифтом, композицией
и движением; данные и форма общие. После выбора варианта дизайн переносится на кодовую базу сайта
ТЕРА ГРУПП (админка, форма заявок на почту, блог, объекты, SEO).

Бриф и принятые решения: [`BRIEF.md`](BRIEF.md), карточка предприятия: `docs/kartochka.jpg`.

## Запуск

```bash
npm install
npm run dev
```

Сборка `npm run build`, проверка собранного `npm start`. Не запускайте сборку при работающем
`npm run dev`: они делят папку `.next`.

## Адреса

| Адрес | Вариант |
|---|---|
| `/` | страница выбора |
| `/c1` | 1. Тёмный, строгая типографика: заставка с прорисовкой знака, горизонтальная лента направлений |
| `/c2` | 2. Светлый, фото на первом месте: слайдшоу, текст проявляется по прокрутке, раскрывающиеся полосы услуг |
| `/c3` | 3. Насыщенный фирменный: название во всю ширину, мозаика, бегущая строка, стопка карточек этапов |
| `/map` | карта будущего сайта |

## Устройство

```
app/
  layout.tsx, fonts.ts   каркас и шрифты (Jost, Onest, Unbounded, Manrope)
  base.css               сброс, общие анимации появления, панель вариантов, разметка формы
  page.tsx, pick.css     страница выбора
  c1/ c2/ c3/            вариант: page.tsx + свой style.css + клиентские компоненты движения
  map/                   карта сайта
components/
  Logo.tsx               знак, перерисован по карточке в SVG (временный)
  Switch.tsx             плавающая панель вариантов, только для показа
  Lines.tsx              заголовок с появлением строк из-под маски
  RequestForm.tsx        форма заявки с проверкой и согласием на обработку ПД
  motion/                плавная прокрутка (Lenis + GSAP) и появление при прокрутке
lib/
  data.ts                реквизиты, тексты, цифры (PENDING: ждёт подтверждения заказчика)
  concepts.ts            описания вариантов и референсы
public/img/              стоковые фото Unsplash, id исходников в docs/unsplash-ids.txt
```

## Данные

Реквизиты настоящие. Цифры команды, условия оплаты и срок КП предварительные, телефон и почта
временные, всё помечено `PENDING` в `lib/data.ts`. Все варианты учитывают системную настройку
«уменьшить движение».

## Публикация

Netlify: настройки сборки в `netlify.toml` (Node 22, `npm run build`), Next.js определяется автоматически.
